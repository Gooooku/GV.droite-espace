# La droite dans l'espace — animations 3D

## Contenu
- `index.html` : la vidéo complète (parties 1 et 2, puis les deux applications), avec chapitres
- `theorie.html` : parties 1 et 2 seules
- `drones.html` : application 1 (les drones)
- `rayon.html` : application 2 (le rayon)
- `lib/` : Three.js et ses modules (inclus dans le dépôt, plus besoin de les charger depuis internet)
- `sw.js`, `manifest.webmanifest`, `icone.svg` : fonctionnement hors connexion et installation sur l'écran d'accueil

## Mise en ligne sur GitHub Pages
1. Sur github.com, crée un nouveau dépôt public, par exemple `droite-espace`.
2. « Add file » → « Upload files » : dépose tout le contenu du dossier, en gardant le dossier `lib` avec ses 3 fichiers.
3. « Settings » → « Pages » → Source : « Deploy from a branch », branche `main`, dossier `/ (root)` → Save.
4. Après une ou deux minutes, le site est disponible à l'adresse `https://<ton-compte>.github.io/droite-espace/`.

## Conseils
- Ouvrir avec Microsoft Edge pour avoir la voix naturelle.
- Après une première visite en ligne, les pages fonctionnent aussi sans connexion.
- Pour publier une mise à jour, remplace simplement le fichier concerné dans le dépôt.
